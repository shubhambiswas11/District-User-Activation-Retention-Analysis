# 📈 District User Activation & Retention Analysis

## 📌 Project Overview

This project analyzes user activation, engagement, and retention metrics across multiple districts using Python, Pandas, and Matplotlib. The objective is to understand user growth patterns, measure product adoption, evaluate retention, and generate insights to support data-driven product decisions.

---

## 🎯 Objectives

- Measure user activation and engagement.
- Analyze Daily Active Users (DAU) and Monthly Active Users (MAU).
- Evaluate 7-day and 30-day retention rates.
- Compare user activity across districts.
- Analyze acquisition sources and platform distribution.
- Identify opportunities to improve user retention and long-term growth.

---

## 🛠️ Tools & Libraries

- Python
- Pandas
- NumPy
- Matplotlib

---

## 📊 Key Analyses

- User Activation Rate
- Daily Active Users (DAU)
- Monthly Active Users (MAU)
- 7-Day & 30-Day Retention Analysis
- District-wise User Distribution
- Revenue by District
- Sessions by District
- Platform Distribution
- User Acquisition Source Analysis
- Age Group Analysis

---

## 📈 Key Insights

- User activation rate is approximately **50%**, indicating half of the registered users become active.
- Average MAU remains stable across the analysis period.
- District-wise analysis highlights variations in user engagement and revenue.
- Platform usage is distributed across Android, iOS, and Web users.
- Paid and organic acquisition channels contribute significantly to user growth.
- Average session duration and session count provide indicators of user engagement.

---

## 💡 Business Recommendations

- Improve onboarding to increase activation rates.
- Strengthen user retention through personalized engagement campaigns.
- Invest more in high-performing acquisition channels.
- Focus retention initiatives on lower-performing districts.
- Monitor DAU, MAU, and retention metrics using a real-time dashboard.
- Use behavioral insights to improve long-term product engagement.
